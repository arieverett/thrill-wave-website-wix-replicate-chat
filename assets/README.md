# Thrill Wave Production Assets v2

Production-ready assets for the Thrill Wave website rebuild.

- Lowercase kebab-case filenames
- Semantic, concise names
- Photos converted to high-quality WebP
- Transparent logos/graphics retained as PNG where appropriate
- EXIF and unnecessary metadata removed
- Oversized raster images resized for practical high-DPI web use
- Redundant variants omitted in favor of canonical files

## Folders
- `brand/thrillwave/` — Thrill Wave brand marks and curated brand portraits
- `clients/` — current client logos
- `team/` — current team portraits
- `portfolio/stills/` — curated portfolio stills and project graphics
- `portfolio/thomas-medical/photos/` — Thomas Medical / healthcare photo library
- `contact/` — map-pin/contact graphics
- `blog/` — flattened semantic blog imagery

- Retained source assets: 163.7 MB

- Reduction: 83.0%
